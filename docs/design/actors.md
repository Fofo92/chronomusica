# Actors

## Contexte

Aujourd'hui, les rôles artistiques sont exercés par des personnes.

Plusieurs cas d'usage suggèrent cependant que certains acteurs collectifs pourraient également jouer un rôle dans Chronomusica :

- familles de musiciens ;
- ensembles ;
- écoles ;
- académies.

## Questions ouvertes

Les acteurs collectifs doivent-ils être représentés explicitement ?

Faut-il introduire un concept d'Actor ou conserver uniquement Person ?

## Décision provisoire

Le modèle reste centré sur Person.

La possibilité d'introduire ultérieurement un concept plus général est conservée ouverte.
